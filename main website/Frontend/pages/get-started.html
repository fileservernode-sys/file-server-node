Step-by-Step Onboarding Guide

Turn an Old Android Phone Into Your Personal File Server

Transform spare mobile hardware into a secure, dedicated personal file storage host. Follow our comprehensive six-step guide to create your account, configure your phone, and access your files remotely without router port forwarding.

What You Need Before Starting

Repurposing an Android phone requires minimal hardware that most households already possess.

1. Spare Android Phone

Running Android 8.0 (API level 26) or higher with at least 2GB of RAM. Older phones with minor cosmetic screen cracks work perfectly.

2. Continuous Power

A standard low-power phone charger and reliable cable to keep the device powered without unnecessary thermal stress.

3. Stable Network

Home Wi-Fi (2.4GHz or 5GHz) or cellular data connection with reasonable upload bandwidth for smooth remote file transfers.

4. Any Web Browser

Chrome, Firefox, Safari, or Edge on any laptop, desktop, or mobile device to access your files remotely with zero client software.

Onboarding Step 4 of 6

Step 4: Name Your Server & Set Dedicated Server Credentials

Configure your server identity and establish separate security credentials for file-level access.

Important Security Distinction: Platform Account vs. File Server Credentials

ZdexCloud enforces dual authentication isolation. Your Platform Account password is used to sign into the website and manage server slots. Your File Server credentials are set directly on the phone to authenticate file operations. This defense-in-depth model ensures that access to your physical phone storage remains strictly protected.

Server Configuration Fields:

  • Server Label: Enter a recognizable name (e.g., Living Room Node, Studio Backup).
  • Server Username & Password: Establish credentials used to authenticate file manager sessions.
  • Start Server Mode: Tap the toggle to initiate the local HTTP server and outbound WebSocket relay tunnel.
Onboarding Step 5 of 6

Step 5: Keep the Phone Connected & Optimize for Continuous Operation

Configure Android OS power management settings to ensure continuous, headless server availability.

1. Whitelist Battery

Go to Android Settings > Apps > ZdexCloud > Battery and select Unrestricted. This prevents Android Doze mode from sleeping the network tunnel.

2. Standard Low-Power Charger

Connect the phone to a standard 5V/1A or 5V/2A charger in a well-ventilated area. If available in settings, enable Android's 85% battery charge protection limit.

3. Screen Off Headless

You do not need to keep the screen on. Press the power button to turn off the display. The server operates headlessly in the background.

Before-You-Start Checklist

  • Phone backed up and factory reset (recommended for dedicated servers)
  • Connected to 2.4GHz or 5GHz home Wi-Fi network
  • MicroSD card formatted and mounted (if using external storage)
  • Screen timeout set and lock screen configured

Continuous Reliability Checklist

  • Battery optimization disabled ('Unrestricted')
  • 'Start on Boot' enabled in app settings
  • Autostart / Background App permissions granted (Xiaomi/Samsung)
  • Phone placed in ventilated area away from blankets or direct sun

Your Android phone server operates continuously in the background independently of whether you are logged into the website. Our strict 24-hour web session security policy applies only to your web browser dashboard: after 24 hours of browser access, your web login expires to protect your account. Troubleshooting

Common Onboarding Issues & Fixes

Quick solutions to the most common setup questions encountered across diverse Android manufacturers.

1. Play Protect Warning During APK Sideload

Because ZdexCloud is installed directly as an APK, Google Play Protect may display a warning dialog. Tap More details and then tap Install anyway to proceed.

2. Server Shows 'Offline' in Web Dashboard

Verify that the phone has an active Wi-Fi or cellular network connection, check that Server Mode is turned on in the app, and ensure the sticky notification is visible in the Android status bar.

3. Android Terminates Background Service Overnight

Certain OEM operating systems (MIUI, One UI, OxygenOS) have aggressive task killers. Ensure ZdexCloud is whitelisted in Settings > Battery > Unrestricted and granted Autostart permissions.

4. Port Forwarding Inquiries

You do not need to configure home router port forwarding or acquire a static IP. The Android app establishes an outbound WebSocket tunnel to our gateway relay, naturally bypassing NAT and CGNAT.
