Complete User Journey

From Registration to Remote File Access

Follow the 10-step sequence that sets up your phone as an accessible personal server without complex router port forwarding or static IP configurations.

End-to-End Sequence

The 10-Step Setup & Remote Access Journey

Clear technical progression from account creation to remote file management.

01

Create Platform Account

Register your user account on the main website using your email address and set your master account password.

02

Verify Email Address

Confirm email ownership via 6-digit OTP code to secure device management permissions and enable server provisioning.

03

Install Android App

Download and install the Flutter Android storage host application on your target phone host.

04

Sign Into App

Authenticate inside the Android app using your main platform account credentials to connect to control plane API.

05

Register Android Device

Link the physical Android phone with your platform account registry (counts as 1 of your 5 allowed server nodes).

06

Configure File Server Credentials

Create dedicated username and password credentials specifically for web file manager access, isolated from your main account password.

07

Start Server Mode

Enable Server Mode on the Android phone to initiate the local HTTP file-serving engine and background service.

08

Secure Outbound Gateway Connection

The app establishes an outbound WebSocket tunnel to our gateway, bypassing CGNAT and eliminating router port forwarding requirements.

09

Server Discovery & Route Resolution

Open the dashboard or server discovery portal to locate your active server instance and resolve its unique subdomain URL.

10

Access & Manage Files Remotely

Log in with your dedicated server credentials to browse, upload, download, and stream personal media directly from your phone storage.

What happens to your files?

Your files remain stored directly on your Android phone's flash storage media. The platform provides software control plane metadata and outbound routing tunnels — it does not act as your central file repository.
