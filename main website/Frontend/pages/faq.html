Frequently Asked Questions

General Questions

It is a platform that converts an unused Android phone into a remotely accessible personal file server. The phone serves as the primary file storage host while our platform handles account coordination, remote discovery, and secure gateway routing.

You can repurpose it into a dedicated 24/7 personal cloud server for hosting photos, videos, documents, and backups without paying recurring cloud storage subscription fees.

Yes. For remote access to be available, the phone must remain connected to power and an active Wi-Fi or mobile network with Server Mode enabled.

Storage & Files

Your files remain strictly on your Android phone's storage media. They are not uploaded to central cloud servers unless you explicitly configure third-party exports.

No. The cloud control plane owns metadata and routing coordination only. Your actual files stay on your physical phone.

Remote Access & Gateway

No. The Android app creates an outbound secure tunnel to our gateway, bypassing the need for public IP addresses or router configuration.

Because the connection is established outbound from the phone to our gateway, local IP address changes do not interrupt your remote endpoint routing.

Security & Authentication

We enforce strict security separation between Platform Account credentials (used for device management) and File-Server credentials (used for accessing actual files on the phone).
