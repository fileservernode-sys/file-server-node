System Architecture

Three unified software pillars

A strict separation of concerns ensures data privacy, high-throughput file transfers, and Zero-Trust isolation.

PILLAR 01

Main Control Website & Registry

Handles user authentication, device ownership verification, 5-server registration limits, device status monitoring, and secure endpoint discovery. Never stores or inspects your personal files.

PILLAR 02

Flutter Android Storage Host App

Executes the background server process on your Android phone, provisions dedicated server authentication credentials, manages Android storage permissions, and maintains outbound WebSocket relay tunnels.

PILLAR 03

Embedded Web File Manager

An ultra-optimized web app compiled directly into the Android application. Provides desktop-grade file browsing, multi-file uploads, media streaming, and directory management directly from phone hardware.

Core Capabilities

Everything needed for personal remote storage

A balanced suite of file management tools designed for high performance on phone hardware.

Full File Operations

Browse, upload, download, move, rename, delete, and organize files into nested directories.

Media Streaming

Stream videos and browse high-resolution photo galleries directly in your browser without downloading first.

Dual-Auth Security

Separated credentials: account credentials manage device pairing; isolated server credentials protect file access.

Unique Subdomain Routing

Each registered server node resolves via its designated unique subdomain endpoint over TLS 1.3.

Hardware Specs

Android Phone Host Hardware Requirements

ZdexCloud is lightweight and designed to run reliably even on legacy mobile hardware.

Operating System

Android 8.0 (Oreo) or higher. Fully compatible with Android 9, 10, 11, 12, 13, 14, and 15 custom ROMs and stock OEM builds.

Memory & CPU

Minimum 1.5 GB RAM and Dual-Core ARM64 / ARMv7 processor. Operates smoothly with minimal memory footprint during file transfers.

Network & Battery

Wi-Fi 802.11 b/g/n/ac or 4G/5G Cellular connection. Battery optimization whitelist setting recommended for uninterrupted 24/7 background hosting.
