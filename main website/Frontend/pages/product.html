COMPONENT 01

Main Control Website

Account registry, device ownership verification, server status reporting, and discovery endpoint routing.

COMPONENT 02

Flutter Android Application

Ultra-lightweight web server hosted on the phone itself for browsing, uploading, downloading, and streaming media directly from phone storage.
