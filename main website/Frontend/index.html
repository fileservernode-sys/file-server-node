Unified System Architecture

Three components. One seamless platform.

The platform combines control plane, device management, and lightweight server hosting into a unified experience.

COMPONENT 01

Main Website

The platform control plane for account management, email verification, documentation, device status monitoring, and server discovery.

COMPONENT 02

Android Application

The Flutter device management application running on your phone to configure credentials, start Server Mode, and maintain gateway health.

COMPONENT 03

An ultra-lightweight file management website served directly from your Android phone for browsing, uploading, downloading, and media playback.

Privacy & Security Principles

Designed around data privacy and local ownership

We believe your personal documents, photos, and records belong on physical hardware under your control.

✓
Local Storage Ownership: Your files reside on your phone's storage media. The central cloud plane holds metadata and endpoint mapping only.
✓
Outbound Secure Architecture: Android servers connect outbound to our gateway, removing the risk of open router ports and exposed home networks.
✓
Strict Credential Separation: Platform authentication manages device registration; dedicated server credentials authorize file operations.
