# ZdexCloud Official Brand Usage Guidelines

## 1. Brand Identity Overview
ZdexCloud empowers individuals to turn unused Android smartphones into secure, private, self-hosted personal cloud servers.

## 2. Name Presentation
- **Correct:** `ZdexCloud`
- **Incorrect:** `Zdex Cloud`, `ZDEXCLOUD`, `zdexcloud`, `RemoteNode`

## 3. Logo Clear Space & Minimum Sizing
- Always maintain a clear margin around the logo equal to at least the height of the central node circle ('x-height').
- **Minimum Digital Sizes:**
  - Full Horizontal Logo: 140px width
  - Compact Logo: 100px width
  - Standalone Symbol: 16px × 16px (Favicon), 24px × 24px (Mobile UI)

## 4. Color Palette
- **Primary Blue:** `#2563EB` (Accessible on white and slate surfaces)
- **Deep Slate Navy:** `#0F172A` (High-contrast typography)
- **Neutral Canvas:** `#FAFAFC` (Warm technical background)
- **Status Emerald:** `#059669` (Online nodes)
- **Status Amber:** `#D97706` (Connecting / Reconnecting)
- **Status Slate:** `#64748B` (Offline nodes)
- **Status Crimson:** `#DC2626` (Error / Alerts)

## 5. Typography
- **UI & Marketing:** Plus Jakarta Sans
- **Metadata & Endpoints:** JetBrains Mono

## 6. Do's and Don'ts
- **DO** use the official vector SVGs whenever possible.
- **DO** maintain proper WCAG 2.2 AA contrast ratios for all UI text.
- **DON'T** distort, stretch, or rotate the symbol.
- **DON'T** apply drop shadows or 3D extrusions to the mark.
- **DON'T** change the colors of the mark or place it on low-contrast backgrounds.
